# Mnemora — Research Status

**Project:** Learnable Memory Policies for Continual AGI Agents  
**Status:** Research proposal / experiment design  
**Owner:** Krishanth

## Current milestone

The research question, hypothesis, formal objective, baselines, evaluation dimensions, and ablation plan have been defined.

## Next implementation milestone

Build a minimal benchmark with deterministic sequential tasks and implement:

1. No-memory baseline
2. Top-k semantic retrieval
3. Recency + importance heuristic
4. Learnable memory controller

## Success criterion

Do not optimize for a headline result. The first milestone is a reproducible comparison under equal memory budgets with multiple seeds and transparent failure analysis.

## Research note

Mnemora is an investigation into adaptive memory for intelligent agents. It is not presented as a complete AGI architecture or as evidence that AGI has been achieved.
