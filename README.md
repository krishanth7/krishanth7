## About

I'm an independent developer and researcher interested in **artificial intelligence, AGI, robotics, and intelligent software systems**.

I enjoy exploring how intelligent systems can **reason, learn, understand information, use tools, and interact with the world**. My work ranges from experimenting with AI models and agentic systems to building software prototypes and exploring robotics.

I learn primarily by **building and experimenting**—turning ideas into prototypes, testing different approaches, studying what works, and continuously refining my understanding.

I'm particularly interested in the intersection of **machine intelligence, software, autonomy, and emerging technologies**.

## What I'm Exploring

My current interests revolve around building and understanding intelligent systems.

* 🧠 **Artificial Intelligence** — machine intelligence, learning systems, and modern AI architectures
* 🤖 **AGI** — reasoning, planning, memory, tool use, autonomy, and general-purpose intelligence
* 🔗 **AI Agents** — agentic workflows, tool calling, multi-agent systems, and autonomous task execution
* 👁️ **Multimodal AI** — systems that work across text, vision, audio, and other forms of information
* 🦾 **Robotics** — autonomous machines, robotic intelligence, perception, and control
* 💻 **Software Systems** — scalable architectures, APIs, developer tools, and intelligent applications
* 🔬 **Research & Experimentation** — testing ideas, studying emerging approaches, and building prototypes
* 🌐 **Open Source** — sharing experiments, tools, and useful software with the developer community
