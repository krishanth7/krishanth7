Cretes — a language for AI-native software

An expressive, statically typed language whose toolchain treats models, prompts and data pipelines as first-class constructs.

Design goals

  • Readable by default — clear syntax over clever syntax.
  • Types that help — inference first, annotations where they pay.
  • AI as a primitive — models and prompts in the type system.
  • Concurrency built in — structured, cancellable tasks.
  • Interoperable — bridges to the JVM and Python ecosystems.
